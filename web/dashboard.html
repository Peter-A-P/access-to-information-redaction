Every decision made here, as it happens

Everyone who reviews a record on this site makes the same decisions a reviewer makes: withhold, release, escalate, or select something the tool missed. This page counts them across every visitor, shows how often people agree with the tool's proposals, and tallies every released PDF the leak test checked before it was sent. It counts and nothing more: no text, no address, no identifier.

What the tool proposed on these records

The {{demo_records_word}} invented records every visitor sees, as the engine proposed them when this server started: the rules, then Jev's recorded answers, replayed. No model is called.

The counts live in the server's memory and start again when it restarts. Each visitor's own session, and its audit log, is deleted after two hours idle; what is counted here is the number of each kind of action and nothing about the person or the text. The raw counts are at /dashboard.json.
